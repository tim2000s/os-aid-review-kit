## The change, in the author's words

Makes the kit run on Linux, macOS and native Windows, adds a Claude Code guard against skipping the gate, and adds size and complexity checks for model-written code.

Cross-platform: global-hooks/* are stub files that source dispatch instead of symlinks; kit/py finds Python 3.11+ (python3, python, py -3) and exits 2 when none is found; dispatch and the installed lefthook.yml run the scripts through it; .gitattributes and newline="\n" keep shell scripts LF; lintgate resolves tools with shutil.which so Windows .cmd and .bat shims run, accepts detekt-cli, and cuts Windows SARIF paths; review.py uses "/" for installed-mode record paths, runs tests through sh where it exists, and gives ambient checkouts a ledger directory under home/ or abs/<drive>/ (migrating the old layout); global.py compares paths case- and separator-insensitively and restores the executable bit. kit-tests.yml runs the suite on all three systems with the real tools, failing any test skipped for a missing tool.

Guard: kit/guard.py is a PreToolUse hook added by `global.py on --claude`. It refuses commands that skip or switch off the hooks, change the gate's settings, run git with another HOME or config, write by shell to records, hooks or settings files, or enter a sign-off; and Edit/Write to those files. Every failure exits 2, the only status Claude Code treats as a refusal.

Size: Ruff template adds C90 and PLR0915; ambient Python repos without a Ruff config get those rules (on both sides of a change or neither); the AGENTS block and default REVIEW.md make an oversized change an important finding.

What could go wrong: the guard is text matching and best-effort, and could block ordinary work (false positives were reviewed and tested) or miss a deliberate evasion (listed in the README). The Windows paths are untested until kit-tests.yml runs on GitHub. The round-3 finding (separators inside a commit message) was fixed after the third review round and is verified by tests only.

## The change, in the author's words

First pushes and new branches with no origin default are measured from the empty tree (`--base :root`)
instead of failing, with a message saying so. The lint gate skips `.review/`, whose scripts are linted
in the kit's own repository; in a target repository they were failing the install commit under the
target's Ruff rules. Records are excluded from TruffleHog through `.review/trufflehog-exclude.txt`,
read by both the commit hook and CI, because a blob hash next to the word "sonar" matches the
SonarCloud detector; the exemption is narrowed to record `.md` files.

What could go wrong: the free text in records (explanations, check output tails) is no longer
secret-scanned anywhere, and a push from a repository whose remote is not named origin is measured
from the empty tree, so every file then needs a record.

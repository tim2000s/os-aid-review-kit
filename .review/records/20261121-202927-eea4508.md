## The change, in the author's words

Fixes the secret scan inside `review.py checks` in ambient mode. Since aea5131 (21 November 2026), `checks` runs `review.py secrets` as a child process. The child inherits REVIEW_TIERS from the parent's enter_ambient, so main skips enter_ambient, AMBIENT stays False, and the child passed `--config trufflehog.yml`, which an ambient repository does not have. TruffleHog exited non-zero and every ambient `checks` run with a live file reported `fail secrets`. It failed closed, not open. cmd_secrets now treats the run as ambient when the repository has no .review, the same test main applies to the gate. Installed repositories keep their own trufflehog.yml. What could go wrong: a .review that exists but is not the kit's would select the repository's config, as main already does. The new test fails against the old code with the original error, passes on a clean change, and fails on a planted split Nightscout token that only the kit's config detects; the full suite passed, 125 tests.

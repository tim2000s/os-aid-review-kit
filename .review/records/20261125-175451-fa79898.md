## The change, in the author's words

In ambient mode a repository with no configuration of its own for detekt, SwiftLint or Biome was linted with the kit's full templates, and Python with Ruff plus complexity and length rules. Those encode a house style the repository never chose: on Boost-autoconfig-rerun they gave 25 new findings, none a defect, among them PascalCase Compose functions, backtick JUnit test names and long Compose screens. Ambient mode now takes its fallback configurations from templates/ambient/, which keep the defect rules and switch off naming, length, complexity, performance and style; detekt's empty-override and generic-exception rules are off too. Ruff runs with its defaults, so the Ruff fallback and ruff-ambient.toml are gone. Installed repositories keep the full templates. The fallback is no longer written where the repository has the linter's configuration under another name (config/detekt/detekt.yml, biome.jsonc), which previously let the kit's file override the repository's own, and biome.jsonc now counts as Biome being set up. What could go wrong: ambient repositories no longer get any automatic size or complexity check, so oversized model-written code there is caught only by the fresh-context review; the SwiftLint and Biome ambient configurations have no test of their own.
